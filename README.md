# DDC Action Receipt (DDCAR)

Experimental, vendor-neutral cryptographic evidence for consequential AI agent actions.

The v0.1 reference implementation is being prepared under a DDC assurance review. It binds human authority, exact action commitments, policy/evidence claims and independently signed execution records. This is not a ratified standard or production payment authorization.

No private DDC/Crystalline implementation is part of this repository. The public reference implementation is Apache-2.0.

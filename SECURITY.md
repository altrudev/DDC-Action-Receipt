# Security policy

This is an experimental reference implementation. It is not approved for production payments, infrastructure administration or physical-device control. Do not use demonstration keys as authority credentials. Do not submit secrets, private DDC implementation, wallet keys or sensitive evidence to public issues.

For a vulnerability, contact inquiry@ddcal.ca with a minimal reproduction and affected version. Avoid publishing exploit details before coordinated review. A security report is not authorization to attack live systems. No response-time or bounty commitment is implied.

Production deployments require independent key custody, trusted identity binding, destination-specific authorization and idempotency, external outcome evidence, revocation/time controls, and a separate operational security review.
